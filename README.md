# Web Application Test Automation

A web automation testing project developed using **JavaScript and Playwright** to demonstrate practical software QA skills.

The project covers end-to-end testing of an employee management system, including login, logout, employee creation, searching, updating, and deletion. It includes both **positive and negative test scenarios** to validate application functionality, input validation, and error handling.
